## Important correctness boundaries

SentinelDroid intentionally does not claim that a normal third-party app can read another application's private sandbox, intercept arbitrary Binder transactions, enumerate every process/service, or decrypt arbitrary HTTPS traffic.

APK DEX/native-library counts are static artifact indicators; they do not prove runtime dynamic code loading.

The VPN containment path is a blackhole-based user-authorized containment mechanism for the MVP. It is not a packet forwarder and does not imply universal control over privileged/system traffic.
