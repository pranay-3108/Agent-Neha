# SentinelDroid schemas

These schemas describe the trust-boundary objects used by the MVP.

`evidence.schema.json` is application/platform evidence and has no command authority.
`security_meta.schema.json` is generated by the SentinelDroid firewall and records detected evidence-manipulation conditions.
`ai_output.schema.json` is analysis/proposal data only. A valid AI output never authorizes an action by itself.
